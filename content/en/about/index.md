# About

I'm a front-end developer based in Taipei, Taiwan.

I enjoy turning ideas into interfaces that feel simple, intuitive, and polished. Most of my work revolves around Vue, React, and TypeScript, but I'm always interested in learning new tools when they solve the right problem.

When I'm not writing code, I'm usually exploring new ideas, learning something new, or figuring out how to make things a little simpler.

## How I Work

I like keeping things simple.

Good frontend development isn't just about making something work. It's about creating a codebase that's easy to understand, a UI that's pleasant to use, and an architecture that can grow without becoming difficult to maintain.

I try to make practical decisions, avoid unnecessary complexity, and pay attention to the small details that make an interface feel finished.

## What I Care About

### Simplicity

I prefer straightforward solutions over clever ones. The best implementation is often the one that's easiest to understand six months later.

### Quality

Clean code, consistent interfaces, accessibility, testing, and performance all contribute to a better product.

### Details

Small interactions and visual details can have a big impact. I enjoy refining those moments until they feel right.

## Technical Focus

My current toolkit includes:

- Vue
- React
- TypeScript
- Tailwind CSS
- Vitest
- Modern web APIs
- Java
- Spring Boot

I'm particularly interested in frontend architecture, reusable component systems, data fetching, authentication, testing, and performance.
